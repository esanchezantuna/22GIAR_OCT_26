En MacOS es necesario instalar las *Apple Developer Tools*, eso suele suponer instalar *XCode* completo o bien solo las *Command Line Tools* (si no se va a necesitar *XCode*). Para esto último hay que entrar en la [web de devlopers de Apple](https://developer.apple.com/download/all/) y descargar el fichero `.dmg` de la versión del SO correcto e instalarlo. De igual manera también habría que instalar *Git* `apt-get install git-all` y *CMake* `apt-get install cmake` en cualquiera de las dos plataformas. ### Visual Studio Code Para usar *Visual Studio Code* como IDE de desarrollo y depuración primero hay que descargarlo e instalarlo desde su [página](https://code.visualstudio.com/). Hay que instalar la extensión para C/C++. Para eso en *VSCode* se pincha en el icono de extensiones en la barra lateral, se busca C++ y se pincha en `Install`. ![Figure [res/000_001]: Extensión de C/C++ en VSCode](res/000_001.png) También es interesante instalar la extensión para *CMake*. ![Figure [res/000_002]: Extensión de CMake en VSCode](res/000_002.png) ### Proyecto Hola Mundo!! Para acabar de finalizar la instalación del entorno de desarrollo y comprobar que se puede compilar y lanzar un proyecto de C++ se va a realizar uno simple de prueba. El primer paso es crear una carpeta para el proyecto y se lanza *Visual Studio Code* desde esa carpeta para abrir el workspace completo. ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ bash linenumbers $ mkdir HelloWorld $ cd HelloWorld $ code . ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [Listing [create_folder]: Crear la carpeta del proyecto en *Bash*] Dentro de *VSCode* se crea un nuevo fichero `main.cpp` donde se escribir el código siguiente que simplemente imprime un "Hello World" en la consola en la salida standard. ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ cpp linenumbers #include int main() { std::cout << "Hello World!!!" << std::endl; return 0; } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [Listing [main.cpp]: Código fuente en C++ del fichero `main.cpp`] Primero se incluye el header `iostream` para usar la salida standard, se crea la función principal de entrada, y luego se saca la cadena de caracteres "Hello World!!!". El siguiente paso es hacer uso de un build system como *CMake* para determinar como se debe compilar y las opciones correctas para el proyecto. Para eso se crea un nuevo fichero `CMakeLists.txt`. ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ cmake linenumbers cmake_minimum_required(VERSION 3.25) project(HELLO_PROJECT LANGUAGES CXX) add_executable(hello_project main.cpp) target_compile_features(hello_project PRIVATE cxx_std_20) ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [Listing [CMakeLists.txt]: Código fuente de *CMake* del fichero `CMakeLists.txt`] La primera línea determina la versión mínima de *CMake* que se debe usar en este proyecto, luego se crear un proyecto llamado "HELLO_PROJECT" que usa el lenguaje C++. Dentro del proyecto se crea un ejecutable llamado "hello_project", que resulta de compilar y linkar el fichero `main.cpp`, más tarde se le dice que use la versión del lenguaje C++20. ### Compilar desde VSCode Ahora solo falta decirle a *VSCode* como debe usar todo eso para crear el proyecto, en este caso se hace a través de un fichero `CMakePresets.json`. ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ cmake linenumbers { "version": 8, "configurePresets": [ { "name": "GCC 14.2.0 x86_64-linux-gnu", "displayName": "GCC 14.2.0 x86_64-linux-gnu", "description": "Using compilers: C = /usr/bin/gcc, CXX = /usr/bin/g++", "binaryDir": "${sourceDir}/out/build/${presetName}", "generator": "Unix Makefiles", "cacheVariables": { "CMAKE_INSTALL_PREFIX": "${sourceDir}/out/install/${presetName}", "CMAKE_C_COMPILER": "/usr/bin/gcc", "CMAKE_CXX_COMPILER": "/usr/bin/g++", "CMAKE_BUILD_TYPE": "Debug" } } ] } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [Listing [CMakePresets.json]: Código fuente del fichero `CMakePresets.json`] Este fichero se puede generar directamente desde *VSCode* abriendo la paleta de comandos `control + shift + P` y seleccionando `CMake: Quick Start`. O bien manualmente, cambiando los settings correspondientes a la instalación del compilador correspondiente en cada maquina particular. En el caso del fichero descrito, se usa el compilador GCC 14.2, el de C está en la ruta `/usr/bin/gcc` y el de C++ en la ruta `/usr/bin/g++`. Ahora ya se tienen todos los ficheros necesarios para la construcción y ejecución del proyecto. Falta configurar las `CMake Tools` para que use estos ficheros. Para ello, en la barra lateral de *VSCode* se busca el botón para `CMake`. Primero se pulsa en la opción de `Configure` dentro del `Project Status` de la sección de `CMake`, concretamente debe poner `[No Configure Preset Selected]`. Al pulsar aquí, en el lápiz, se abrirá en la Paleta de Comandos una opción para seleccionar el compilador adecuado, y se verá en la parte inferior en la ventana de `OutPut` como *CMake* se pone a verificar que el compilador sea accesible y capaz de compilar código C++ válido. ![Figure [res/000_003]: CMake en VSCode](res/000_003.png) A continuación hay que decirle que `target` se quiere compilar y ejecutar, es decir, el ejecutable. Para ello, en la sección `Build`, en la línea `[Targets in Preset]`, se pulsa el lápiz. En la paleta de comandos, en este caso, se selecciona el `target` que corresponde al ejecutable que se ha creado en el `CMakeLists.txt`, `hello_project`. Si todo ha ido bien, se podrá lanzar ya la tarea de construir el ejecutable. Para ello se puede pulsar el botón a la derecha de la sección `Build`, y luego para lanzar el ejecutable el botón a la derecha de la sección `Launch`. También se pueden realizar estos dos pasos desde la parte inferior izquierda de la barra inferior de *VSCode*, en los botones `Build`, y `Launch`. De esta manera, si no hay ningún problema se podrá ver el resultado de la compilación en la ventana de `Output`, donde habrá un mensaje de `build` exitoso, o en caso contrario, la lista de errores encontrada. ![Figure [res/000_004]: Resultado de la compilación](res/000_004.png) El resultado de la ejecución se puede ver en la terminal. ![Figure [res/000_005]: Resultado de la ejecución](res/000_005.png) ### Compilar desde línea de comandos Se puede usar *VSCode* como editor de código y compilar y ejecutar desde línea de comandos, usando directamente `CMake` para ello. En este caso, habría que crear manualmente una carpeta `build` dentro del proyecto, y lanzar los comandos de compilación desde ella. ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ bash linenumbers $ mkdir build $ cd build ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [Listing [create_folder]: Crear la carpeta para el `build` en *Bash*] Y luego desde esa carpeta se lanza el comando `cmake ../` para que coja el fichero `CMakeLists.txt` de la carpeta raíz del proyecto y con ello genere el proyecto. ![Figure [res/000_006]: Generación del proyecto `cmake`](res/000_006.png) Se puede usar directamente este mismo `cmake` para construir y compilar el ejecutable. Con la siguiente instrucción `cmake --build . --target hello_project --config Debug`. Se llama a `cmake`, se le especifica que se quiere usar para construir el ejecutable con la opción `--build` sobre la carpeta actual `.`, se selecciona el `--target` dentro del `CMakeLists.txt`, `hello_project`, y por último se indica la configuración de `Debug`. Si todo ha ido bien, y no hay ningún error de compilación o linkado, deja en la carpeta `build` el ejecutable `hello_world`, que se puede llamar inmediatamente para verificar su correcta ejecución. ![Figure [res/000_007]: Compilación del ejecutable](res/000_007.png) ### Windows Si se usa Windows como sistema operativo, la forma más sencilla y directa para obtener un entorno de desarrollo completo es usar *Visual Studio*, que es el IDE completo de MS para desarrollar y compilar proyectos en C++.
